> 본 문서의 전략은 Setup C (OU-MR)로 지칭하며, 기존 Branch C/D는 향후 별칭 E/F로 재명명 권장.

## 1. 가설 (Hypothesis)

**H1.** 박스권 국면에서 BTCUSDT 가격이 국소 평균 이탈의 Ornstein-Uhlenbeck 과정
`dX = θ(μ − X)dt + σdW` 로 근사되며, 통계적 국면 게이트(VR < 1)를 통과한 구간에서
|z| ≥ z_entry 이탈은 평균으로 회귀하는 경향이 있다.

**H2.** 국면 게이트를 적용한 시점의 게이트 미적용 시점 대비 승률과 기댓값이 크다.
(게이트의 개별 기여를 on/off 비교로 측정)

**H3.** 본 전략은 트레이드별 손익이 Setup A/B와 낮은 상관을 가진다
(신호원이 가격 과정 통계이므로). 상관 측정은 검증 항목.

## 2. 이론적 근거

- **OU 과정 / AR(1) 추정**: 5분봉 로그가격 X_t에 대해 ΔX_t = α + βX_{t-1} + ε 회귀.
  θ = −ln(1+β)/Δt, 반감기 t½ = ln2/θ. β ≥ 0이면 평균회귀 부재 → 거래 금지.
- **Variance Ratio (Lo–MacKinlay 1988)**: VR(q) = Var(r_q) / (q·Var(r_1)).
  VR < 1 → 평균회귀 국면. 랜덤워크 귀무가설 하 점근분포로 z-통계 산출 가능.
- **평균 실패의 이론적 정의**: 지정한 3×t½ 경과에도 z가 z_exit 이내로 미회귀 시
  OU 가정 위배로 간주하고 시간 청산. 시간 청산이 우연적 원인이 아닌 추정 반감기의 함수.

## 3. 트리거 조건 (전부 충족 시에만 진입)

기준 타임프레임: **5분봉** (1분봉은 마이크로구조 노이즈, 1시간봉은 표본 부족)

| # | 조건 | 파라미터 (초기값 = 가설, 최적화 결과 아님) |
|---|------|----------------------------------------|
| G1 | VR 게이트 | vr_q = 4, vr_window = 288봉(24h), VR < vr_threshold = 0.85 |
| G2 | 반감기 유효성 | AR(1) β < 0 이고 t½ ∈ [hl_min=10, hl_max=120]봉 |
| G3 | z-score 이탈 | zscore_window = min(max(3×t½, 30), 300)봉, \|z\| ≥ z_entry = 2.0 |
| G4 | 박스 내부 확인 | 가격이 lookback 24h 고정 범위의 [5%, 95%] 분위 내 (경계 돌파 중 진입 금지) |
| F1 | (필터, on/off) 펀딩 정렬 | 포지션 방향과 반대로 \|funding\| > 0.0005/8h 시 진입 차단 |
| F2 | (필터, on/off) 이벤트 블랙아웃 | 고임팩트 지표 ±15분 진입 금지 |

방향: z ≥ +2.0 → 숏, z ≤ −2.0 → 롱 (대칭. 단, 양방향 비대칭성 검증 위해 롱/숏 원장 분리)

## 4. 청산 규칙

- **TP (평균 회귀)**: z가 z_exit = 0.5 이내 진입 시 즉시 청산.
- **SL (하이브리드)**: max(구조적 이탈, k×ATR). 구조적 이탈 = 진입 시점
  zscore_window 내 극값 ± sl_buffer_pct = 0.0015. ATR: 14봉(5m), k = 1.5.
- **시간 청산**: 지정한 3×t½ 경과 시 시장가 청산 (OU 가정 위배 판정).
- **재진입**: 동일 방향 max_reentries = 1, 손절 청산 후 cooldown = 1×t½.

포지션 사이징: 고정 R (스탑 거리 역산). Setup A/B와 동일 원칙.

## 5. 효과크기 예측 (사전 등록 — 사후 성과 개선 아닌, 방향성 예측)

- P1: 게이트 통과 구간의 평균 성공률(3×t½ 내 z_exit 도달)이 미게이트 구간보다 크다.
- P2: 보유 시간 중앙값 ≈ 1~2×t½ (OU 이론 값과 정합해야 함. 크게 벗어나면 모델 부적합 신호).
- P3: 롱측과 숏측의 실현 헤지비트론 비대칭 (하방 급락 특성상 롱측이 더 나쁠 것으로 예측).

## 6. 기각 조건 (Hard rejection)

최소 30 샘플(롱/숏 각각) 확보 후:
1. 손익구조에서 도출한 손익분기 승률(BE-WR) 대비 실측 승률이 평탄하고 기댓값 ≤ 0
2. P2 위배: 보유 시간 중앙값 > 2.5×t½ (평균근 이론 위배로 시그널이 잡히지 못함 → OU 모델 기각)
3. VR 게이트 on/off 비교에서 게이트의 기여가 0 이하 (H2 기각 → 국면 필터 로직 재설계)
4. Setup A/B와 트레이드 손익 상관 > 0.6 (H3 기각 → 분산 효과 없음, 포트폴리오 가치 상실)
